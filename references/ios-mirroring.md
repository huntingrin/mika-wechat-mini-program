# iOS 通道：iPhone 镜像 + phone-harness

没有 adb、没有 Mika 时，iPhone 也能跑，但**只能靠截图 + OCR + 坐标**。这里记的是 2026-11-03 在
iPhone 15 Pro Max + macOS 上实跑瑞幸小程序的完整路径和边界。

## 前置

| 项 | 要求 |
|---|---|
| 系统 | macOS（iPhone 镜像.app 可用） |
| 手机 | 已配对、在 Mac 附近、**锁屏且没人使用** |
| 工具 | `uv tool install phone-harness`（用它的 Python 跑，带 Quartz / Vision） |
| 权限 | 屏幕录制（截图）、辅助功能（键入） |

```bash
PY="$(uv tool dir)/phone-harness/bin/python"
$PY scripts/ios_bridge.py state     # ok=false 时会告诉你卡在哪
```

`state.ok=false` 的三种常见原因：`连接中断`、`iPhone 使用中`、`正在连接` / `解锁iPhone`。
这三种都只能由人处理：把手机放到 Mac 旁边、锁屏、别碰。

## 已验证的路径（瑞幸，2026-11-03）

```
桌面搜索 → 微信 → 微信搜索「瑞幸」→ 网络结果「瑞幸咖啡小程序」
→ 小程序资料卡 → 点卡片进小程序 → 底部「我的」→「优惠券 9张」→ 我的优惠券列表（停在「去使用」前）
```

关键动作：

```bash
# 1. 回桌面，点桌面搜索
$PY scripts/ios_bridge.py home
$PY scripts/ios_bridge.py tap 搜索

# 2. 中文输入：先 pbcopy，再 ⌘V。type_text 会粘成乱码（「瑞幸」→「饿」）
printf '瑞幸' | pbcopy
# 然后用 osascript/Quartz 发 ⌘V，或直接用 bgphone.key("cmd+v")

# 3. 点搜索结果（图标在标签上方约 55pt）
$PY scripts/ios_bridge.py longtap 瑞幸咖啡小程序 --duration 0.3

# 4. 小程序内：tab、按钮都要按住
$PY scripts/ios_bridge.py longtap 我的 --duration 0.2
$PY scripts/ios_bridge.py longtap 优惠券 --duration 0.2
```

## 按压时长（实测）

| 目标 | 时长 | 说明 |
|---|---|---|
| 微信原生列表 / 搜索框 | 短点 | `tap` 即可 |
| 小程序 tab、普通按钮 | 0.2–0.35 s | 短点会被静默丢弃 |
| 小程序里的表单/「立即参与」类按钮 | 0.45–0.9 s | 太短没反应，太长出长按菜单 |
| 桌面 App 图标 | 0.22 s | 超过 0.45 s 弹长按菜单 |

**「点了没反应」几乎都是按太短**，不是坐标错。

## 坐标必须按截图算

OCR 返回的 y 和实际位置会差 30–60pt（不同页面不一样），**不能直接拿 OCR 坐标去点**。
可靠做法：

1. `shot` 拿一张图（图与窗口 1:1）；
2. 在图上量出目标像素坐标；
3. 屏幕坐标 = 窗口原点 + 图像坐标；
4. 立刻点，别缓存 —— 窗口尺寸会变（342×746 → 490×1074 → …）。

## 硬限制（别硬试）

| 限制 | 表现 | 处置 |
|---|---|---|
| **小程序「账户登录」页不接收合成点击** | 勾选框、一键登录、手机号登录，短点/长按/双击全无反应；同页返回键和 tab 正常 | **人工闸门**：让用户解锁手机登录一次，登录态留在小程序里 |
| 真机被使用 | 镜像立刻结束，显示「iPhone 使用中」 | 让用户锁屏、别碰，再点「连接」 |
| 连接中断 | 「确保 iPhone 在 Mac 附近、已开机、最近解锁过」 | 同上；锁屏≠关机 |
| 无 AX / 无 CDP | 读不到元素树，只能 OCR | 只做「看得见 + 点得到」，不做稳定选择器 |
| 中文输入 | `type_text` 粘成乱码 | `pbcopy` + `⌘V` |
| 无多点触控 | 捏合缩放不可用 | 需要缩放时用页面自带按钮 |
| 窗口不可改尺寸 | `set_window_frame` 报错 | 坐标按当前窗口算 |

## 什么时候算跑通

- 每步都有截图证据（OCR 文本 + 画面）
- 到达目标页（例：我的优惠券列表），**停在不可逆按钮前**（去使用 / 去喝一杯 / 支付）
- 结果为页面原文，不是「应该成功了」

## 与安卓通道的分工

| | 安卓（Mika / adb） | iOS（镜像 + OCR） |
|---|---|---|
| 读页面 | 元素树 + 文本 | 截图 OCR |
| 点 | 元素级 | 坐标 + 按压时长 |
| 稳定性 | 高 | 中，页面一变就要重算坐标 |
| 登录墙 | Mika 可一键登录 | 登录页点不动，必须人工 |
| 适合 | 整条流程 | 导航、读页、单次点击 |
