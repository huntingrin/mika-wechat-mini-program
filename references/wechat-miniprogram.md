# 微信侧操作要点

## 1. 公众号身份核验

微信搜索出来的同名号很多，选之前先看**资料页**：

- 名称下方的**主体**（例：瑞幸咖啡（北京）有限公司）
- 蓝色**认证标**
- 地区、简介

确认后再进聊天。搜到多个候选时，让 Mika 把候选列表念出来，人工挑，不要「取第一个」。

## 2. 关键词触发的自动回复

发完关键词，回复形态决定后面能不能走：

| 形态 | 后续 |
|---|---|
| 小程序卡片（带「交易保障」角标） | 直接点，最顺 |
| 文字链接 | 可能是 H5，看是否要跳浏览器 |
| 二维码图片 | 只能人工扫，桌面/自动化到此为止 |

卡片文案通常包含活动期和规则摘要，先读再点，能提前发现「限时 2 天」「每人每天 1 次」这类约束。

## 3. 小程序登录墙

首次进活动小程序，常见顺序：勾选《用户协议》《隐私政策》→ 一键登录。

- 这属于**授权**，不是付款，Mika 可以做，但要保持「只点登录，不点任何领取/购买」的禁令
- 如果微信本身掉登录（出现验证码/密码页），Mika 会停在 `waiting_on_phone`，只能人工

## 4. 怎么判断「今天还有没有次数」

活动页**经常不显示剩余次数**，别指望页面告诉你。三个替代信号：

1. 「中奖记录」为空 → 大概率没用过
2. 抽奖按钮可点（不是灰的「活动已参与」）→ 还有次数
3. 活动规则里的「每人每天 N 次、当天有效、未抽视为放弃」

抽完之后按钮会变灰、文案变成「活动已参与」，记录里新增一条带时间的券 —— 这是最硬的证据。

## 5. 易混淆项

活动页上常有多个奖池并存，别混：

- 主活动奖池（例：1 万张 0 元券 / 10 万张 11.9 元券 / 89 万张 8.3 折券）
- 横幅子活动（例：「超大杯免费喝！1000 张先到先得」）
- 页面顶部标题和主视觉文案不一定是同一个活动名

回报结果时必须区分「哪个池子的券」，并抄原文。

## 6. 券的常见限制（抽完才看得到）

- 有效期：规则页常写「自发放之日起 N 天内有效」，弹窗里未必显示
- 适用范围：「部分饮品可用」「新品不可用」
- 履约方式：「仅限自提订单」「不支持外送」→ 直接决定「0 元券不等于免配送费」
- 门店例外：「快闪店 / 交通枢纽 / 旅游景区 / 特别声明门店不支持」
- 不可与其他优惠同享、不可转赠

## 7. 失败态文案

| 文案 | 含义 |
|---|---|
| 活动已参与 | 当天次数已用，别再试 |
| 已抢完 / 库存不足 | 奖池空，重试无用 |
| 请先登录 / 授权手机号 | 登录墙，人工或一键登录 |
| 活动已结束 | 时间窗过了，检查活动期 |
